# VerseBox — Tiny Line Viewer

**VerseBox10 — Borderless, Pin & Narration, themes **
A small, calm verse display app for Windows. One line at a time, borderless, always-on-top if you want it, with narration and 10 rich backgrounds.

---

## What it does

- Shows one verse / line at a time, centred
- Resizable window — background stretches to fill the window
- Borderless mode (`F11`) — clean overlay look
- Pin position — lock it in place so you don't drag it by accident
- Shuffle, Random verse, Next / Previous
- Copy current verse (`Ctrl+C`)
- Open your own verse file (`Ctrl+O`)
- Font size + opacity controls
- Narration (TTS) — speaks the current verse
- Auto-narrate on verse change
- Remembers your last theme, font, position and file (config in AppData)

## Themes — 10 backgrounds

All backgrounds are `1200x340` PNGs, flowers / decoration at the edges, empty centre for the verse. They stretch to fit whatever size you drag the window to.

| Shortcut | Theme | Verse text | Why that colour |
|---|---|---|---|
| `Ctrl+1` | Original Dark | Light grey | Dark solid |
| `Ctrl+2` | Green Emerald | Cream | Dark emerald |
| `Ctrl+3` | White Marble | Gold | Light marble |
| `Ctrl+4` | White Marble (Night) | Light grey-blue | Dark marble |
| `Ctrl+5` | Mint Floral | **Black** | Light mint — black reads best |
| `Ctrl+6` | Pink Floral | **Black** | Light pink — black reads best |
| `Ctrl+7` | Autumn Sunset | **Black** | Bright golden centre — black reads best |
| `Ctrl+8` | Navy Gold Floral | **White** + gold info | Dark navy — black would vanish |
| `Ctrl+9` | Red Scroll | **White** | Bright red — white pops, black is low contrast |
| `Ctrl+0` | Navy Glory | **White** + light-blue info | Dark navy — black would vanish |

You can also switch from the **Themes** menu — you don't have to remember shortcuts.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `Space` / `Right` / `Down` | Next line |
| `Left` / `Up` | Previous line |
| `R` | Random verse |
| `S` | Toggle shuffle |
| `Ctrl+C` | Copy current verse |
| `Ctrl+O` | Open verse file |
| `Esc` | Close app |
| `F11` | Toggle borderless |
| `Ctrl+Up` / `Ctrl+Down` | Font bigger / smaller |
| `Ctrl+Right` / `Ctrl+Left` | Opacity up / down |
| `Ctrl+1` … `Ctrl+0` | Switch theme (see table above) |
| `N` | Speak current verse |
| `Ctrl+N` | Toggle auto-narrate |

Mouse wheel also goes next / previous.

## Verse file format

Plain text file, one verse per line. Example:

```
In the beginning God created the heaven and the earth.
And the earth was without form, and void...
```

Use `Ctrl+O` to pick a file. The app remembers it next time.
